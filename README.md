## 2. 我偏好的 AI 回答风格
- **语言**：必须使用简体中文。
- **语气**：直接、客观、讲人话。不需要客套话（不要写“作为一个人工智能...”）
- **详细程度**：直奔主题，先给结论，再给解释。
- **代码/步骤**：提供可直接复制运行的完整代码或分步骤教程。

- **长文总结**：
  > 请将以下内容提炼成 5 个核心要点。用 Markdown 表格输出，第一列是要点，第二列是具体解释。
- **头脑风暴**：

- **翻译润色**：
  > 请将以下文字翻译成专业的商务英语，并解释其中 3 个高级词汇的用法。
